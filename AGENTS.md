## Agent skills

### Review workflow

Leave changes uncommitted for the user to review in the editor. Commit, push, or open a PR only when explicitly requested. Run `pnpm check` before handing back completed code changes.

### Product context

Before product planning or implementation, read `docs/specifications.md` for the system spec, feature specs, and the decision map.

### Issue tracker

Track issues and specs in GitHub Issues for InzynierPROTeam/inzynierpro.
Read `docs/agents/issue-tracker.md` before tracker operations.

### Triage labels

Use the five default triage labels.
Read `docs/agents/triage-labels.md` before triaging or applying labels.

### Domain docs

Use a single-context layout.
Read `docs/agents/domain.md` before exploring the codebase.

### Client queries

Before adding or changing client queries or query keys, read [ADR-0024](docs/adr/0024-shared-http-contracts-and-client.md) for module layout, Effect execution, and hierarchical cache invalidation.
