# Jawna pauza egzaminu próbnego

Egzamin próbny można dowolną liczbę razy wstrzymać i wznowić, bez obniżenia wyniku punktowego. Jawna pauza zatrzymuje zegar i zasłania pytania; podczas pauzy nie można przeglądać pytań ani zmieniać odpowiedzi. Samo zamknięcie aplikacji lub utrata połączenia nie wstrzymuje zegara. Backend kontroluje upływ czasu i stan pauzy, a po wyczerpaniu limitu kończy podejście na podstawie ostatnich zapisanych odpowiedzi.

Wybieramy możliwość przerwania ćwiczenia zamiast wymagania nieprzerwanej symulacji egzaminu. Żeby zachować kontekst porównywania wyników, podsumowanie wskazuje użycie pauzy, a podejście zachowuje czas rozwiązywania, łączny czas pauz i ich liczbę.
