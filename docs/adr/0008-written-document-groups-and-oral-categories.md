# Documents as written categories, separate oral categories

In written study the reference document is the study category, as statutes were in V1; no extra category mirrors a document. Oral study keeps its own categories, which may be topical or named after a document; a category is not assumed to be a document. A question's primary place in the catalog is separate from its source links, and a question may use many sources. Similar tile, progress and catalog views may share UI components without forcing identical database entities. We rejected a shared category entity with a mandatory document mapping for written study, and independent topical written categories, because neither has a product need today.

An oral question has one primary category and may be assigned to many paths. Assignment is per question, not per category: two questions in one category may belong to different paths. The shared question content stays shared.

Each path orders its own documents and oral categories, so the most important material comes first for that path: a document or category matters differently for, say, design and site management qualifications. A path document and a path oral category carry a position unique within the path. The sources list, the document package, written categories, oral categories and the next category chosen for a session all follow it. A path oral question names its category, which must be on the path. We rejected a global category order because one order cannot put the most important categories first on every path.

The user may choose a district chamber on each path assignment, validated against the path's general chamber, and use it as an extra filter for oral questions on that path. A regional link connects an oral question with a district chamber and records whether it comes from an exam-taker's recollection or an official pool source. The backend model and the preview filter exist before the chamber UI. Regional links do not copy question content. We distinguish exam-takers' recollections from official pool sources. The default scope is every question on the path; the "Reported in my chamber" filter narrows to questions with that link without suggesting that other questions cannot appear in the exam. The preview shows the scope and question count.

The regional filter affects selection only. History and SRS stay shared for the path and study kind. A started session keeps its set; changing the chamber or filter affects new sessions, and there are no parallel sessions per chamber.
