# Jednorazowy import katalogu V1

Przed pełnym importem wykonujemy próbę na reprezentatywnych pytaniach pisemnych, ustnych, opracowaniach i przypisaniach do ścieżek. Sprawdzamy mapowanie, kompletność relacji i wyświetlanie treści, a następnie importujemy cały katalog. Pierwsze wydanie może zawierać wszystkie dostępne materiały V1.

Importer jest jednorazowy. W razie niepowodzenia resetujemy docelową bazę V2 przygotowywaną do importu i wykonujemy import od początku. Nie budujemy synchronizacji, historii uruchomień, obsługi konfliktów kolejnych importów ani dodatkowego rejestru identyfikatorów pochodzenia. Procedura dotyczy przygotowania nowej bazy przed udostępnieniem jej użytkownikom; nie resetowania V1 ani późniejszej historii nauki.

Najpierw wiernie przenosimy treść i relacje do nowego modelu. Poprawki językowe i merytoryczne oraz propozycje AI są osobnym etapem redakcyjnym. Oryginalny materiał wejściowy pozostaje dostępny do sprawdzenia poprawności przeniesienia i pochodzenia, bez rozbudowanego mechanizmu śledzenia w aplikacji. Redaktor zatwierdza publikację i potwierdzenie zgodności odpowiednio do dostępnych dowodów; import i redakcja AI nie nadają automatycznie statusu zweryfikowanego materiału.
