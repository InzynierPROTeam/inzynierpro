# Analiza jakości pytań w tle

Rozwijamy analizę wzorców odpowiedzi w tle, aby wskazywać redakcji pytania potencjalnie niejednoznaczne, nieskuteczne warianty błędnych odpowiedzi i zmiany wyników po aktualizacji treści. Analiza uwzględnia rewizje i kontekst prób zamiast traktować sam odsetek błędów jako dowód wadliwości pytania. Sygnały służą przeglądowi redakcyjnemu, bez automatycznej zmiany poprawnej odpowiedzi lub publikacji. Szczegółowe wskaźniki ustalamy przy specyfikacji funkcji; analiza nie wymaga własnej integracji API modeli AI.

Osobistą diagnostykę słabych obszarów tematycznych i wynikające z niej rekomendacje nauki odkładamy na przyszłość. Nie są wymagane na start; bieżący dobór powtórek pozostaje odpowiedzialnością SRS.
