# @inzpro/config

Public configuration shared by organization applications.

**Runtime:** Universal JavaScript.

Own branding, contact details, locale defaults, social links and store identifiers. Keep environment loading, credentials, deployment configuration and business rules with their owners.

## Usage

```ts
import { appName } from '@inzpro/config/app'
```

## Dependencies

The permitted workspace directions are defined in [policy.ts](../tools/src/oxlint/architecture-policy.ts). Follow the [architecture guide](../../docs/architecture.md) for imports, wildcard exports, test exceptions and verification.
